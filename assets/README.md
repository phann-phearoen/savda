# Assets

This folder contains placeholder files for a metadata-complete website setup.

Recommended final files and size targets:
- favicon.ico — legacy browser fallback, any supported ICO export :x
- favicon.svg — vector icon, scalable SVG :x
- favicon-32x32.png — 32x32 px :x
- favicon-64x64.png — 64x64 px :x
- apple-touch-icon.png — 180x180 px (recommended iPhone/iPad icon) :x
- icon-192.png — 192x192 px :x
- icon-512.png — 512x512 px :x
- maskable-icon.png — 512x512 px minimum, ideally 1024x1024 with safe padding :x
- og-image.png — 1200x630 px (recommended social preview size) :x
- twitter-image.png — 1200x675 px or 1200x630 px :x
- logo.svg — scalable vector logo, no fixed size required :x
- logo-mark.svg — scalable vector brand mark, no fixed size required
- mstile-150x150.png — 150x150 px :x
- browserconfig.xml — metadata file referencing the Windows tile image

Replace placeholders with final exported artwork for production.
